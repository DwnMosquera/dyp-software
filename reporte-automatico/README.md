# Reporte Automático

## ¿Qué vamos a construir?

Desarrollaremos un programa que procese datos de ejemplo para generar un resumen y una gráfica de resultados. Estará dirigido a personas y equipos que necesiten comprender información de forma rápida y organizada. El programa manejará datos incorrectos, ejecutará un proceso semanal mediante GitHub Actions y publicará sus resultados en GitHub Pages.
