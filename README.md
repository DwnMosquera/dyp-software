# DYP Software

## ¿Quiénes somos?

DYP Software es un equipo de desarrollo de software enfocado en crear soluciones tecnológicas para automatizar tareas y mejorar procesos. Trabajamos colaborativamente para desarrollar soluciones organizadas y de calidad.

## Organización del repositorio

- `README.md`: presentación de la empresa y del equipo.
- `CONTRIBUTING.md`: reglas para trabajar en equipo.
- `.gitignore`: archivos que Git debe ignorar.
- `src/`: código fuente del proyecto.
- `docs/`: documentación y bitácoras.
- `equipo/`: perfiles profesionales de los integrantes.

## Forma de trabajo

Cada integrante trabaja en su propia rama y propone los cambios mediante un Pull Request. Otro integrante debe revisar y aprobar los cambios antes de fusionarlos en `main`, respetando las reglas de protección del repositorio.
